# Velora

POS and business management UI for Next.js 14 (App Router, plain JS, no UI library).

    npm install
    npm run dev

Pages: /login, / (Overview), /sales (POS), /products, /inventory, /purchasing, /customers, /reports, /settings.
Mock data is in lib/data.js and currency formatting (IDR) in the `idr` helper there. Brand files are in public/brand.
